## 3. 한국어 관련 사실

- 🔷 **Kakao 거래소(`poe.kakaogames.com`)는 3.30에서 정상 운영 중**이다. 리그 목록·필터·아이템·스탯 데이터가 모두 한국어로 제공된다(2026-11-17 HTTP 200). → 한국어 가격 검색 경로가 유효하다(PHASE 0의 ❓ 해소).
- 🔷 신규 항목의 한국어명이 거래소 데이터에 있다. 예: 심연 실낱(Abyss Thread), 해진 실낱(Frayed Thread), 실낱의 메이븐의 끌, 영혼 핵 4종, 균사체 핵, 비전의 연결, 살덩이 카테고리 등.
- ✅ PoEDB 한국어 페이지는 UI만 한국어이고 **아이템명은 영어**다 → 한국어 이름의 원천으로는 쓸 수 없다. 한국어 이름은 **로컬 Kakao 클라이언트 데이터 또는 Kakao 거래소 API**에서 가져와야 한다.

## 4. 이름 비교만으로 "신규"를 가릴 수 없는 이유 (주의)

Kakao 거래소 items/static을 현재 `ko/items.ndjson`과 단순 이름 비교하면 수백 건의 "없음"이 나온다. 그러나 대부분은 레거시 아이템, 몬스터/리그스톤 같이 원래 데이터에 넣지 않는 항목, 번역 표기 차이다. 따라서 **"3.30 신규 목록"은 클라이언트 데이터(3.29 대비 3.30) diff로 확정**해야 하며, 이는 데이터 생성기(PHASE 2-1)의 첫 산출물로 삼는다.
