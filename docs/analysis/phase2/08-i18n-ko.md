# 한국어 UI 번역 보완

## 결과

- 영어 기준으로 누락된 한국어 키 27개를 모두 추가했다.
- 기존 `t()` 호출에 대응하는 공통 키와 새 UI 번역 키 48개를 en/ko 양쪽에 추가했다. 최종 두 카탈로그는 각각 384개 문자열을 가지며 중첩 구조, 키 순서, 들여쓰기와 숫자 치환자 구성이 일치한다.
- 한국어 카탈로그에 이미 존재하지만 값이 영어였던 설정 탭, 가격 확인 설정, 속성 필터 설명, 가격 조회 상태 등도 번역했다.
- 메인 프로세스는 설정을 받기 전 한국어를 사용하고, `cfg.language === 'ko'`이면 한국어, 그 밖의 언어이면 영어를 사용한다.

## 범위 및 CSS 확인

- 번역 대상 Vue/TS를 검색하고 템플릿의 영어 텍스트와 title/placeholder, 리터럴 `t()` 호출을 점검했다.
- 브랜드, 언어 선택기의 자국어 표기, Ctrl/Alt 같은 키 이름, px 같은 단위, 거래소/예측 서비스 원문, 게임 속성 및 검색 표현식, 사용자 편집 가능한 저장된 위젯 제목과 예시 설정 데이터는 유지했다.
- 로그, 개발용 오류 및 주석 처리된 디버그 UI는 번역 대상에서 제외했다.
- Fontin small-caps는 별도 폰트 파일을 사용하는 구조이며 사용자 UI의 강제 uppercase/text-transform은 검색되지 않았다. 한국어 locale이 HTML lang에 반영되는 기존 흐름을 이용해 한국어 글꼴을 지정했다. 실제 실행 화면의 시각 검증은 수행하지 않았다.
- `tools/`, `*.ndjson`, `client_strings.js`는 수정하지 않았다. git, hc send, 서브에이전트, 네트워크, 패키지 설치를 사용하지 않았다.

## 검증

| 검사 | 결과 |
| --- | --- |
| renderer `npm test` | 통과: 3개 파일, 20개 테스트 |
| renderer `npm run lint` | 통과: 오류 0개, 경고 4개. 기존 eslint-disable 미사용 경고 (`RateLimiter.ts` 1개, `common.ts` 3개) |
| renderer `npx --no-install vue-tsc --noEmit` | 통과; 설치 및 네트워크 사용 방지를 위해 `--no-install` 지정 |
| main `npx tsc --noEmit` | 생략: `main/node_modules` 없음 (작업 지시의 생략 조건) |
| 메인 번역 스모크 검사 | renderer의 설치된 TypeScript로 메인 번역 모듈과 AppTray를 메모리에서 변환 후 Electron 모의 객체로 실행. 기본 한국어 4개 메뉴, en/ru/cmn-Hant 영어 fallback, ko 복귀, 최신 단축키 안내, 관리자 권한 다이얼로그 문구 통과. 전체 main 타입 검사나 Electron 실기동을 대체하지 않음 |
| en/ko JSON | 파싱 성공, 384개 키 구조·순서 및 숫자 치환자 집합 일치 |
| 전역 리터럴 `t()` 키 | en 카탈로그 누락 없음 |

메인 스모크 검사의 최초 실행은 테스트 하네스에 default import 상호 운용 옵션이 없어 실패했다. 하네스에 `esModuleInterop`을 설정한 재실행은 통과했으며 제품 코드를 바꾸어 우회하지 않았다.
